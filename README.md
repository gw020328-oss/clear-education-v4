# CLEAR · 교육 환급 조건 검증 및 지급 모듈

환급 안내문을 검토 가능한 조건으로 구조화하고, 외부 기록 검증 결과를 사전 예치된 재원의 지급으로 연결하는 해커톤 프로젝트입니다. 장기 목표는 대형 어학원 환급반에 적용하는 것입니다.

## 현재 상태 · 2026.10.10

| 구분 | 확인한 범위 |
| --- | --- |
| 기존 시제품 | AI 초안·사람 검토·서명·예치·직접 청구의 로컬 구현. `legacy/`는 선택한 소스 191개를 보존한 참고본입니다. |
| 과거 YBM 실험 | 별도 진단 환경에서 실제 계정 1개의 응시자·성적 증명을 연결했습니다. 개인정보 및 원본 증명은 공개하지 않습니다. |
| 새 버전 v4 | PRD·기술 설계·환경 준비, ProofAdapter 오프라인 합성 시험 36개 통과. |
| 아직 미완료 | 새 실제 YBM 증명과 지급의 통합, 일반 PC 수집 흐름, 삭제 검증, 비개발자 사용 시험. |

**합성 시험 통과는 실제 YBM 연결이나 지급 성공을 뜻하지 않습니다.** 기존 Amoy 검증기 시험은 로컬 포크의 호환성 확인이며 공개 체인 지급은 실행하지 않았습니다.

## 역할과 신뢰 경계

- **AI:** 조건 초안·원문 근거·누락과 충돌 검토를 돕습니다. 운영자가 조건을 확정하며 AI는 지급을 승인하지 않습니다.
- **외부 기록:** TOEIC은 Reclaim 증명을 검증하고, 학습 기록은 이번 MVP에서 시드 API를 사용합니다. 실제 학원 API와 실명 본인확인은 후속입니다.
- **검증 서버:** 출처·신청·지갑·기록 연결과 고정된 조건을 검사합니다. 이 판정과 지급 권한 발급의 신뢰는 남습니다.
- **스마트컨트랙트:** 최소 지급 권한 확정 후 참가자가 기한 내 직접 청구하도록 하는 구조입니다. 자격 발급 전 CLEAR의 잘못된 판정·거부까지 해결하지 않습니다. 로컬 체인은 기능 검증용입니다.

MVP 기준은 **TOEIC 총점 800점 이상 AND 필수 강의 수강률 80% 이상**입니다. 새 실제 증명과 로컬 테스트 자금 지급을 연결하고, 합성 자료를 사용할 수 있는 비개발자 2명 사용 시험을 별도로 진행할 계획입니다.
