# W02 실제 YBM 접속 경로 연결

2026-10-11, `origin/develop`의 PR #1 병합 커밋 `dd7ec920fafbaf44ee9ac848f6fabb9ee5e7a467`에서 `codex/ybm-live-collector`를 만들었다. 원본 코드·과거 실험 실행기·증명·개인 Chrome 프로필은 재사용하거나 변경하지 않았다. 추천 모델은 GPT-6 Astra / High이며 사용자가 해당 설정으로 변경했다고 확인했다.

## 확인한 결과

공식 Attestor 연결을 통해 익명 YBM 홈페이지의 HTTP 200과 TOEIC 페이지 내용을 확인했다. 인증서 검증을 켠 상태에서 같은 연결을 전용 Chrome의 HTTPS 중계에 사용했고, 종료 뒤 프로필 삭제까지 성공했다. 이 결과는 로그인 성공이나 성적 증명 검증 결과가 아니다. 상세 범위는 [검증 기록](ybm-route-verification.json)에 남긴다.

기존 성공 경로의 같은 client 유지 방식을 새 수집기에 연결했다. 고정한 attestor-core 5.1.4는 `AttestorClient` 생성자를 공개하지 않으므로 공식 pool factory를 worker당 한 번만 호출한다. 한 worker는 한 세션만 처리하고, 연결이 끊기면 프로필을 정리하고 종료한다. 새 worker·새 프로필·새 로그인 없이 client를 교체하지 않는다. 후속 증명 함수에는 이 client 객체를 직접 전달해야 한다.

TLS 구현을 초기화하지 않으면 최초 RPC 식별자 생성부터 실패하므로 공식 webcrypto 구현을 먼저 설치한다. SDK를 실제로 불러와 암호화 초기화·protobuf init 응답·종료·동일 worker 재생성 금지를 검사하는 메모리 소켓 시험을 추가했다.

## 구현 경계

- `src/ybm-collector/`: 고정 의존성, 공식 WebSocket, 세션 전용 HTTPS CONNECT 중계, 익명 공개 페이지 확인, 로그인 경로 실행.
- `src/mac-collector/`: 기존 잠금·관리형 저장·강제 종료 복구를 유지하고 명시적 접속 모드만 추가. 기본 실행과 기존 ZIP은 계속 합성 저장 경계 도구다.
- 중계 주소는 임시 IPv4 loopback 포트다. HTTPS 443과 YBM 관련 세 도메인 계열만 허용한다. CONNECT 밖의 요청, Origin 헤더가 있는 CONNECT, 임의 포트·사용자 정보·경로·우회 도메인은 거부한다. TLS를 해독하거나 루트 인증서를 설치하지 않는다.
- CDP는 상속 파이프만 사용한다. 브라우저 제어·쿠키·원본을 돌려주는 로컬 HTTP API가 없다. 다만 CONNECT 중계 포트 자체에는 사용자 인증이 없으므로 같은 기기의 다른 프로세스가 허용 호스트에 연결을 시도할 수 있다. 로컬 악성 프로세스 격리를 보장하지 않는다.
- Chrome의 암묵적 loopback 우회, QUIC와 프록시를 거치지 않는 WebRTC를 막는다. 지정 중계가 실패하면 직접 접속으로 전환하지 않는다. 일반 Chrome에 대한 설정은 변경하지 않는다.
- 최대 활성 터널 32개, 다운로드 대기 2 MiB, WebSocket 업로드 대기 2 MiB, 메시지 4 MiB, 소켓/RPC 시간 제한을 둔다. 실제 계정 사용성·대용량 서비스 처리량을 검증한 수치는 아니다.
- 수집 worker와 자식 Chrome의 core dump 한도를 0으로 고정한다. 현재 실행의 자식 프로세스에만 적용하며 전역 OS 설정을 바꾸지 않는다.
- 실행 최대 30분, 창 닫기·명시적 종료·오류·연결 단절 때 정리한다. 강제 종료 후의 기존 다음 실행 복구 정책도 유지한다.
- 로그인 모드는 Network/Fetch 수집을 켜지 않으며 쿠키 조회·HTML 읽기·원본 전달·증명 생성·지급을 수행하지 않는다. 계정 정보를 콘솔이나 보고서에 출력하지 않는다.

## 시험과 보존

신규 접속 시험 27개, 신규 실제 Chrome 프록시 시험 2개, 기존 회귀 251개로 총 280개를 통과했다. 새 Linux CI 시험은 외부 연결을 막고 합성 Attestor와 메모리 소켓만 사용한다. Mac CI에는 실제 Chrome의 합성 프록시 거부·우회 금지 시험을 포함한다. 공식 공개 페이지 확인은 로컬에서 별도로 실행했으며 CI에는 넣지 않는다.

[최초 구현 커밋 CI](https://github.com/gw020328-oss/clear-education-v4/actions/runs/38119265257)의 공개 이력·Linux 합성·Mac 복구 3개 작업도 통과했다. 후속 변경까지 포함한 최신 결과는 PR 검사에서 확인한다.

원본 소스 191개 및 기존 경로 실행기 3개 내용 지문이 기존 manifest와 일치했다. `verify:workspace:local`도 통과했다. 원본 참고 문서 지문과 별도 공개 문서 지문을 보존했고, 과거 TEE·tmpfs 결과는 수정하지 않았다. 비공개 원본 증명·쿠키·키는 읽지 않았다. 실험 디렉터리 전체의 새 포렌식 검사를 수행했다는 뜻은 아니다.

## 아직 남은 연결

**현재 단계는 실제 수집 경로 중 로그인 전송 경로까지 구현한 것이다. 실제 성적 수집 전체가 완료된 것은 아니다.** 사용자 로그인, 신청·수취 지갑과 owner 사전 결합, 실제 원천 정책, 새 proof 생성·공식 서명 검증, 800점·80% 평가와 로컬 지급은 남아 있다. `liveCollectionEnabled`는 계속 false다.

다음에는 신청/지갑 결합 및 최소 원천 정책을 수집 명령에 연결하고, 로그인 후 지정된 두 원천만 메모리에서 처리하도록 한다. 이 준비를 마친 뒤 사용자의 실제 로그인을 요청한다. 로그인 경로만 먼저 수동 점검할 수는 있지만, 이번 익명 확인만으로 불필요한 재로그인을 요구하지 않는다. 기존 `MAC_MVP.ko.md`의 10월 14–17일 결합 단계와 18–21일 실제 증명·지급 기준을 유지한다. 다음 작업 추천도 GPT-6 Astra / High다.

## 재현

저장소 작업본에서는 먼저 `./tools/npm --prefix src/ybm-collector ci --ignore-scripts`를 실행한다. 외부 계정 없는 시험은 `./tools/npm --prefix src/ybm-collector test`, Mac 합성 회귀는 `./tools/node --test tests/mac-collector/*.test.mjs`다.

공식 공개 페이지 확인은 `./tools/node src/mac-collector/launch.mjs --public-route-check`다. 이는 외부 네트워크를 사용하지만 로그인하지 않는다. 검토된 수동 로그인 경로 확인은 `--ybm-route`이며 기존 합성 ZIP에는 포함하지 않았다. 개인 프로필이나 테스트 저장 경로로 실제 접속을 켤 수 없다. 성적 증명용 설치 패키지 및 처음 쓰는 참여자 사용성 검증은 별도 후속이다.
