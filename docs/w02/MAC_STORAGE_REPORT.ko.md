# Mac 저장 경계 구현과 합성 시험 결과

승인된 Mac 관리형 저장 정책을 별도 v4 작업본에 구현했다. **신규 시험 17개, 강제 종료·재시작 보정 후 반복 10회, 압축을 푼 패키지 실행이 통과했다.** 실제 YBM 수집·지갑 결합·지급은 아직 이 도구에 연결되지 않았으며 로그인은 필요하지 않다.

추천 모델은 **GPT-6 Astra / High**다. 민감정보 수명·프로세스 종료·다른 신청의 자료 격리를 함께 검토해야 하는 단계다. 문서의 추천은 실제 실행 모델을 변경했다는 뜻이 아니다.

## 구현 범위

- `src/mac-collector/storage.mjs`: 사용자 전용 앱 경로, 소유자·권한·상위 symlink 검사, FileVault 확인, 앱 경로에 한정한 Time Machine 제외, 세션 생성과 정리. 브라우저 세션과 보관 자료 디렉터리를 구분한다.
- `chrome.mjs`: 개인 프로필과 분리한 Chrome, 세션별 프로필·캐시·임시 경로, 디버그 포트 대신 상속 파이프, 다운로드 거부, 검증된 전용 Chrome 프로세스 그룹 종료.
- `launch.mjs`·`worker.mjs`: 운영체제 파일 잠금으로 동시 실행 차단, 살아 있는 기존 작업자 확인, 정상·오류·신호 종료 정리, 강제 종료 뒤 남은 세션을 새 실행 전에 정리. 검증 실패 시 새 수집으로 진행하지 않는다.
- 서버 원본 처리용 `RawProofMemory`: 신청별 분리, 128 KiB·16건 상한, 24시간 만료, 발급/오류 시 해제 API와 버퍼 덮어쓰기. 실제 서버의 인증·검증·발급 흐름에 연결하는 작업은 남아 있다.
- 자체 Node를 포함한 Apple Silicon Mac용 ZIP과 사용 안내. 현재는 **합성 저장 경계 시험 패키지**이며 Apple 공증된 배포 앱이나 실제 YBM 수집기는 아니다.

현재 Mac에서 FileVault 활성화와 새 앱 경로의 Time Machine 제외를 확인했다. 개인 Chrome 프로필, 기존 원본·실험 자료, 전역 swap·백업 설정은 바꾸지 않았다. 새 전용 앱 폴더에는 실행 후 `.lock`만 남고 세션 디렉터리는 제거되었다.

## 시험 증거

| 항목 | 결과 |
| --- | --- |
| 단위·통합 시험 | 17/17 통과. 권한·symlink·삭제 범위·살아 있는 작업자·중복 실행·메모리 원본 격리와 만료 |
| 실제 설치된 Chrome | 합성 localhost HTTP-only 쿠키 전달 및 정상 종료 후 프로필 삭제 |
| 강제 종료 | 작업자를 SIGKILL로 종료해 잔여 세션을 만들고 다음 실행에서 정리. 보정 후 10회 반복 통과 |
| 종료 중 프로세스 정보 | 일시적으로 명령행 확인이 안 되면 잠시 재조회. 계속 불일치하면 종료/삭제를 거부. 다른 프로세스를 종료하는 우회 없음 |
| 배포 패키지 | 포함 파일 SHA-256 확인, 압축 해제 후 포함된 Node로 실행·프로필 삭제 통과 |
| 의존성 확인 | 고정 ethers·ganache·solc와 메모리 내 계약 컴파일 통과. 배포/체인 실행 없음 |
| 원본 보존 | 원본 26,857개·실험 92,550개 항목의 경로·mode·크기·수정시각 지문 동일. 원본/legacy 소스 191개 각각 내용 지문 일치 |

초기 시험에서 macOS `/var` symlink를 시험 경로로 사용해 경로 검사가 거부되었다. 시험 전용 경로만 실제 경로로 해석하도록 수정했고, 제품의 symlink 거부는 유지했다. 재시작 시험에서는 종료 중 Chrome 프로세스 식별이 일시적으로 실패해 정리가 중단되는 경우를 발견했으며, 신원을 확인하지 않은 프로세스에 신호를 보내지 않는 재조회 방식으로 보정했다.

기존 `verify:workspace`는 이전 문서 링크 수정 때문에 참고 PRD 지문이 W01 기록과 달라 여전히 실패한다. 이번 작업은 W01 지문이나 동결 참고본을 바꾸지 않았다. 원본/legacy 소스 검사는 별도로 통과했으며, 이 기존 실패를 신규 17개 시험 성공과 합쳐 ‘전체 검사 통과’라고 보고하지 않는다. 이전 spike 전체 회귀는 변경이 없어 재실행하지 않았다.

## 적용한 보관 예외

정상·오류 종료에는 즉시 정리를 시도하고, 실행 중에는 최대 24시간을 적용한다. 강제 종료·전원 종료 뒤 남은 자료는 다음 실행 전에 정리한다. 앱 미실행 중 정시 삭제는 보장하지 않는다. 파일 삭제는 저장 장치에서 복구 불가능한 소거를 뜻하지 않는다. SDK 문자열·OS swap·스냅샷·타사 백업·운영체제 진단 자료까지 없애는 보장은 하지 않는다. 실제 수집 전 사용할 기기의 별도 백업·관리 도구도 확인한다.

프로세스 신원이나 파일 권한이 불확실해 정리를 완료하지 못하면 새 실행을 차단한다. 사용자 소유의 다른 브라우저를 강제 종료하거나 검사를 무시하는 자동 우회는 없다. 실제 브라우저의 모든 시작·중단 타이밍을 검증한 일반 배포 품질 주장도 하지 않는다.

## 이어서 진행할 실제 연결

1. 공식 Attestor 하나의 client를 브라우저 연결과 증명 생성에 함께 사용하는 경로를 이 전용 프로필에 연결한다. 필수 원천 추출 규칙을 고정하고 예상 밖 응답·빈 추출·임의 문맥을 거부한다.
2. 새 신청·수취 지갑·nonce·owner·원천 정책과 공증자 서명을 검증하는 실제 adapter를 연결한다. 추가 TEE와 분리한 보장 수준을 화면·증거에 명시한다.
3. 수집 연결의 합성 리허설과 저장/로그 검토 후 사용자에게 새 YBM 로그인을 안내한다. 기존 쿠키·증명 파일을 복사해 성공으로 세지 않는다.
4. 지갑·정책·금고·발급·독립 청구 단계를 결합해 본인 실제 로컬 지급을 검증한다. 이어 다른 사용자 자기 PC/계정 수집과 별도 두 명의 합성 사용성 시험을 진행한다.

다음 실제 연결 단계도 **GPT-6 Astra / High**를 권고한다. 이 저장 준비만으로 W02 전체 또는 11월 7일 제품 목표가 완료된 것은 아니다.
