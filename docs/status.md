각 시험의 수를 합산해 정확도나 제품 완성률로 사용하지 않습니다. 상세 근거는 [감사 기록](reference/AUDIT.ko.md)과 [W02 결과](w02/REPORT.ko.md)에 있습니다.

## 다음 단계

1. 공식 동일 Attestor client 경로를 전용 Mac 수집기에 연결하고 실제 원천 정책·지갑·문맥 결합 확인
2. 합성 수집 리허설 뒤 사용자 새 로그인 안내 및 최소 추출·저장·삭제 검증
3. 새 실제 증명을 새 신청에 연결하고 800점·시드 수강률 80% 판정과 로컬 지급 검증
4. 중복·변조·기한·장애·직접 청구 및 삭제 검사
5. 다른 사용자 자기 PC·계정 실제 수집 최소 1건과 별도 비개발자 2명 합성 사용성 시험

실제 증명 시연과 합성 자료를 사용한 사용자 체험은 별도 결과로 보고합니다. 수동 provider 작성 도구의 오류는 기존 직접 생성 경로 전체가 실패했다는 의미가 아닙니다.

## 후속 범위

실명 본인확인, 실제 학원 API, 원화 지급, 공개 Amoy 지급, 여러 교육기관 지원과 실제 도입·예치 의향 검증은 후속 과제입니다. [PRD](reference/PRD.ko.md)

추가 TEE는 명시적 결정으로 후속 보장으로 분리했습니다. 기존 TEE 검사가 통과한 것으로 바꾸지 않습니다. 최신 기준은 [Mac MVP 변경](current/MAC_MVP.ko.md), 저장 준비 결과는 [Mac 보고서](w02/MAC_STORAGE_REPORT.ko.md)를 따릅니다. `main`의 현재 기준본은 완성 서비스가 아니며 협업 전환 PR은 검토 전 자동 병합하지 않습니다.
