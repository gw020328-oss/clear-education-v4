# Mac 저장 경계 확인 도구 사용 안내

이 안내의 대상은 기존 ZIP과 기본 실행의 **합성 자료로 Chrome 격리·종료 후 삭제를 확인하는 시험 도구**다. 이 합성 도구에는 실제 계정 정보를 입력하지 않는다. develop 소스의 별도 진단 모드에는 [실제 YBM 증명 생성·독립 검증 기록](../w02/YBM_PROOF_REPORT.ko.md)이 있으나, 그 기능을 포함한 제품 배포나 지급 완료를 뜻하지 않는다. develop에는 [합성 정책·평가](POLICY_EVALUATOR.ko.md), [영속 신청](WALLET_APPLICATIONS.ko.md), [금고·최종 동의·예치 확인](VAULT_ENROLLMENT.ko.md)도 추가됐지만 이 기존 ZIP에 포함된 기능은 아니다. 금고 검증은 메모리 EVM·무가치 TEST 토큰 범위다. 최신 범위는 [개발 현황](../status.md)을 확인한다.

## 준비와 실행

Apple Silicon Mac에 Google Chrome이 설치되어 있고 FileVault가 켜져 있어야 한다. Node 실행 파일은 패키지에 포함되어 있으므로 따로 개발 도구를 설치할 필요가 없다.

1. ZIP을 풀고 `시작.command`를 실행한다. 출처를 확인할 수 없다는 경고가 나타나면 멈추고 패키지 출처와 지문을 확인한다. 이 패키지는 Apple 공증 배포본이 아니며 보안 설정을 끄도록 안내하지 않는다.
2. 새 전용 Chrome 창에 합성 자료 확인 화면이 나타난다. 개인 Chrome 창이나 계정으로 로그인하지 않는다.
3. 완료되면 전용 창이 닫히고 ‘임시 프로필을 삭제했습니다’라는 메시지가 표시된다.
4. 중단하려면 실행 창에서 Control+C를 누른다. 강제 종료 후에는 같은 도구를 다시 실행해 남은 임시 자료를 먼저 정리한다.

새 임시 경로는 `~/Library/Application Support/CLEAR/collector-v4`이며 첫 실행 때 이 디렉터리만 Time Machine에서 제외한다. 기존 자료나 전역 백업 설정은 바꾸지 않는다. 같은 사용자에서 두 개를 동시에 실행하면 두 번째 실행을 막는다.

오류가 나면 화면의 간단한 오류 문구만 공유한다. 쿠키, 비밀번호, 성적표, 브라우저 프로필 폴더를 보내지 않는다. ‘정리하지 못했습니다’가 표시되면 재시도 전에 기존 전용 창이 종료되었는지 확인한다. 개인 Chrome 프로필을 지우지 않는다.

## 보관의 한계

정상·오류 종료 때 임시 세션을 삭제한다. 전원 종료나 강제 종료로 남은 파일은 다음 실행 전에 정리한다. 앱이 꺼져 있는 동안 24시간 이내 삭제나 디스크 모든 흔적의 완전 삭제를 보장하지 않는다. 타사 백업·기업 관리 도구가 임시 경로를 복사하는지도 확인해야 한다.

이번 시험이 성공해도 실제 YBM 증명·다른 사용자 호환성·로컬 지급이 성공한 것은 아니다. 이 합성 ZIP 안내를 실제 로그인 절차로 사용하지 않는다.
