## 승인된 시원스쿨 혜택 범위 — M0.2

최신 승인으로 시작이반 **750점반 50/100/200/300%의 조건 판정·환급액 계산을 개발 목표**에 포함한다. 400%는 조건 구조화와 제출자료 Vision 사전검토까지만이다. YBM 주 시연을 유지한다. 이번 구현물은 명세·합성 사례·검사이며 제품 런타임은 미구현이다. 500%·전강좌반·토스/오픽 부가 혜택은 제외한다. 이전 100% 전용 범위는 이 결정으로 대체한다.

2026-10-14 [공식 상품 안내](https://lab.siwonschool.com/?s=event&t=refundhalf3)를 다시 열어 750점반 열과 공통 유의사항을 대조했다. 아래는 기수/구매 옵션 적용을 확정한 실행 정책이 아닌 근거 매핑이다. 공통 후기·주체·인정 기간·신청 기한은 tier의 대안 경로 밖에서 적용한다.

원문 위치는 로컬 HTML 3667~3755행의 표와 3753행 이후 챌린지/공통 환급 안내다. 웹 재열람에서도 같은 대상 열의 조건을 확인했지만 새 raw HTML 지문을 생성하거나 과거 지문과 전체 페이지 동일성을 주장하지 않는다. 과거 이력의 기준 표현은 수강 신청일이며 전체 성적·계정/이름 대조 안내를 확인했다. 정확한 날짜 경계·상위 tier의 과거 목표 점수·원천 완전성 입증은 Q-S다. [공식 근거와 현재 한계](EXAM_HISTORY_REQUIREMENTS.ko.md)를 함께 읽는다. 응시료 ‘0원’은 사용자 비용에 관한 혜택 문구일 수 있어 환급액에 더할 금액 0으로 자동 변환하지 않는다.

후속 공개 조사와 브라우저 재열람에서 [상세 가이드](https://blog.naver.com/siwonschoollab/223244039814) 본문을 확인했다. [후기·챌린지 사전검토 명세](REVIEW_PRECHECK.ko.md)에 200byte 후기, 100일 내 연속 14일 게시, 제목/태그·8장·800자·지정 문구/링크의 근거와 미결을 분리한다. 문구 위치는 원문 내 충돌이 있고 계산/적용 방식도 OPEN이다. 이미지만으로 실제 공개·연속 게시·작성자·진위를 검증하지 않는다. 기존 blog-*의 guideStatus=UNAVAILABLE는 과거 보류 fixture로 보존하며 현재 가이드 확보 상태를 나타내지 않는다.

최초 제출 성적·성적표 단회 환급·혜택 중복 제한은 확인했으나 tier 간 적용 선택/우선순위와 정정 처리는 OPEN이다. 복수 충족을 단순 max나 합산으로 정산하지 않는다. 상위 tier 가능성이 미확인인데 하위 금액을 조용히 확정하거나 하위 지급 후 상위 차액을 자동 추가 지급하지 않는다. 구체 합성 선택과 실제 미결을 [계약](M0_CONTRACT.ko.md)에 분리한다.

`official-questions`와 `siwon-questions` fixture는 질문 화면의 축약 예제다. 이 표의 모든 질문을 망라한 실제 정책이 아니다. 실제 초안은 적용되는 질문을 모두 포함해야 한다. 질문에 답해도 근거/권한·지원 여부가 해결되지 않으면 게시 불가다. 합성 가정으로 답한 경우 새 합성 버전만 만들 수 있다.

외부 질문을 기다리지 않고 시작할 수 있는 범위는 위 합성 선택의 **mock 화면 차이 분석·상태표·설계**다. M1 이후 기능 착수와 실제 API·DB·체인·유료 모델 연결은 이 M0 승인에 포함되지 않는다.

## H1 후속 결정 / 남은 질문

[등록 이력 → 목표 성적](EXAM_LIFECYCLE.ko.md)은 기존 clear-m0.2와 별도인 clear-exam-lifecycle.1 합성 계약이다. 실제 #32 표 공증 성공을 계정 전체 기간 검증으로 올리지 않는다. 합성 선택은 서버 시험 clock의 TERMS_ACCEPTED, 과거 730일 [from,until), 수집 유예 600초, 최초 수락 목표 시험 고정이다. 모두 공식 경계/최초 제출 규칙의 확정이 아니다. Q-S/Q-TIER/Q-C0/Q-PRIVACY/Q-CONSUMER는 유지하며 실제 등록 사건·허용 오차·증거 보존/삭제·정정/복원 정책은 H2/M3의 미결이다.
