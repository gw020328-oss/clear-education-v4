11/5 오후 기능 동결과 11/6 본선에 맞춰 독립 AI 비교 패널과 운영효과 패널을 만들어줘. 현재 PR139의 참가자·운영자 정상 흐름과 core web, 라우트, main은 A 담당이 소유한다. 새 파일에서 패널을 만들고 기존 파일 연결은 A와 파일별 인계 후 진행해줘.

운영효과는 자동 처리 논리 건수, 조건·신청 분모, 서버 처리 구간, 오류·재시도, 사람 개입을 보여줘. 필수 양측 동의와 예외 검토, 사람 실작업과 대기시간은 분리해줘. 동일 사례 수작업 비교가 없거나 baselineComparable=false이면 절감률은 N/A로 표시해줘. 멘토 예시 수치는 실적으로 표시하지 마.

B/C가 제출하고 본부가 확정한 DTO에만 API를 연결해줘. 공통 파일, 루트 패키지, CI, 서명·동의·지급 의미의 변경은 본부와 조율해줘. 8분 리허설에서 정상 지급과 AI 비교는 합계 약 2분을 목표로 해줘. 지연되면 차트·조건 조합·원문 강조부터 줄여줘.

작업 파일, 기준 SHA, fixture·실제 모드 구분, 검증 결과와 통합에 필요한 파일을 인계해줘.
