# PR149 E5B 실행 시간 진단

대상은 PR149의 `6298dc4bcffafa855809ab525c0337f9b7a28611`, 기준 develop은 `a5653d64b939da9a1ededc85744d30b91c759f8f`다. 사용자 실실행이 아닌 격리 합성 CI를 진단했다.

## 재현 근거

[실행 41751519259](https://github.com/gw020328-oss/clear-education-v4/actions/runs/41751519259)의 첫 시도와 재실행 모두 기존 30분 job 제한으로 취소됐다. 재실행 job은 `126330862783`이다.

| 재실행 단계 | 관측 결과 |
| --- | --- |
| E5B 파일 순차 실행 | 1,603.609초, 90개 중 81 성공 / 9 기존 opt-in skip / 0 실패 |
| 개별 성공 시험 시간 합계 | 1,585.859초: 단계 시간의 약 98.9% |
| API·저장소 회귀 | 149.668초, 911개 성공 / 0 skip |
| 보존·지문·workspace·의존성 검사 | 성공, 약 3초 |
| 공개 이력 검사 | 763 commits / 4,145 blobs에서 PASS 출력 후 job 취소 |

이는 종료되지 않는 한 시험이나 callback 교착의 증거가 아니다. 81개 체인 시험을 파일 단위로 모두 순차 실행한 누적 시간에 설치·회귀·보존·이력 검사 시간을 더하면 job 제한에 도달한다. 특히 실제 시계를 사용하는 ACCEPT 권한 만료 시험 두 개는 각각 약 82초/81초이며, 코드는 원래 `binding.expiresAt`까지 실제로 기다린다. 기존 주석의 68개 시험 기준은 현재 시험 수와 맞지 않았다.

## 수정과 격리 근거

같은 job에서 E5B 파일 실행만 `--test-concurrency=2 --test-isolation=process`로 변경한다. 파일 안의 시험은 기존 순차 실행을 유지한다. timeout 30분, 시험 glob, 모든 후속 검사와 권한·트리거·Geth 이미지·Node 버전은 동일하다. 시험 코드, assertion, skip 조건, 지급·서명·원천·권한 만료 기준은 변경하지 않는다.

- Node의 파일별 프로세스 격리로 prototype 패치·환경 변수·fetch mock·컴파일 캐시는 다른 파일과 공유하지 않는다.
- `createEnvironment`는 매 호출마다 UUID 환경 디렉터리, Docker 컨테이너·네트워크, 무작위 chain ID·역할 지갑을 생성한다. RPC와 HTTPS는 OS가 지정하는 loopback 포트를 사용한다.
- SQLite·controller·envelope·TLS 파일은 해당 환경 디렉터리에 있다. 재시작 시험은 자기 환경 ID만 넘기고, 종료·network 정리는 동일 owner/image를 확인한다.
- 합성 registered-source fixture의 host 디렉터리도 UUID를 포함한다. 고정 결과 파일을 쓰는 self-Attestor 시험은 기존 opt-in 조건을 유지하며 별도 기존 CI에서 검증한다.
- 두 프로세스만 실행하여 동시 체인·컴파일 부하를 제한한다. 현재 권한·시계 경계 검증을 빠른 가짜 시계로 바꾸지 않는다.

변경한 workflow SHA-256을 v62 intake와 E5B source-pin 검사에 정확히 고정하고, memory consumer 및 E5 보존 지문을 함께 갱신한다. 과거 v60/v61 guard와 원래 호환 기록은 변경하지 않는다. 주석을 제외한 workflow 비교에서 유일한 변경이 E5B 파일 동시 실행 옵션임을 확인했다.

최종 로컬 실행 시간과 최신 커밋의 CI 결과는 PR149에 기록한다. 이전 7/8 성공을 새 커밋 전체 성공으로 취급하지 않는다. 실제 로그인·사용자 서명·새 지급·유료 모델 호출은 수행하지 않는다.

## 로컬 수정 검증

고정 Node 24.21.0에서 동일 E5B glob 전체를 두 파일씩 실행해 804.948초(13분 25초)에 완료했다. 결과는 기존 CI와 동일한 90개 중 81 성공 / 9 opt-in skip / 0 실패 / 0 취소다. 시계 경계·권한 철회·실제 시간 만료·합성 100 TEST 지급과 중복 청구 차단 시험을 유지했다. 소스 호환 55개, E5/E5B 보존·211개 소스 지문도 통과했다. 로컬 OS와 원격 runner는 다르므로 개선 비율은 원격 CI 결과로 최종 확인한다.
